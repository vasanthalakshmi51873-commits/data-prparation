# Data Preparation and Cleaning Project

## Dataset
Titanic Dataset

## Objective
The objective of this project is to identify and clean missing values,
duplicate records, incorrect data types, and inconsistent values.

## Tools Used
- Python
- Pandas
- GitHub

## Data Cleaning Steps

1. Loaded the Titanic dataset.
2. Checked for missing values.
3. Checked for duplicate records.
4. Checked data types.
5. Removed duplicate records.
6. Filled missing Age values using the median.
7. Filled missing Embarked values using the mode.
8. Filled missing Cabin values with "Unknown".
9. Converted Age and Fare into numeric data types.
10. Saved the cleaned dataset.

## Output

The cleaned dataset is saved as:

cleaned_titanic.csv

## Conclusion

The Titanic dataset was successfully cleaned using Python and Pandas.
The cleaned dataset can be used for further data analysis and machine
learning tasks.
